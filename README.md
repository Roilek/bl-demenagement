# B&L Déménagement — site web

Site one-page bilingue (FR / EN) de B&L Déménagement : déménagement, débarras, nettoyage,
avec calculateur de volume et demande de devis en ligne.

Réalisé par [Opteamize](https://opteamize.ch).

## Fonctionnement

- **Hébergement** : GitHub Pages, gratuit. Toute modification sur la branche `main`
  est en ligne en 1 à 2 minutes.
- **Demandes de devis** : envoyées par [Web3Forms](https://web3forms.com), gratuit
  jusqu'à 250 demandes par mois. Elles arrivent par e-mail ; « Répondre » écrit
  directement au client.
- **Aucun serveur, aucun abonnement.** Le site vous appartient entièrement.

## Modifier le site

Le plus simple : connectez votre assistant IA (Claude, ChatGPT…) à ce dépôt GitHub et
demandez-lui la modification en français (« change le numéro de téléphone »,
« ajoute une question à la FAQ »…). Le fichier `AGENTS.md` lui explique comment
le site est construit et ce qu'il ne doit pas casser.

En cas de problème, chaque modification est enregistrée dans l'historique GitHub :
on peut toujours revenir à la version précédente.
